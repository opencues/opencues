# Feature Concepts

Platform-agnostic feature specifications. Each integration implements these concepts with its own UI.

| # | Feature | Description |
|---|---------|-------------|
| 1 | [Navigation](navigation.md) | Move between words, navigation modes |
| 2 | [Cycling](cycling.md) | Replace words with alternatives, numbers, gender |
| 3 | [Visual States](visual-states.md) | Normal, dimmed, highlighted |
| 4 | [Cursor Preservation](cursor-preservation.md) | Adjust cursor when words change length |
| 5 | [Linked Words](linked-words.md) | Words that must change together |
| 6 | [Tips](tips.md) | Instant per-word hints from local JSON |
| 7 | [LLM Alternatives](llm-alternatives.md) | Grammar, math, factual sources |
| 8 | [Fill-in-the-Blank](fill-in-the-blank.md) | Underscore placeholder filling |
| 9 | [Multi-Word Spans](multi-word-spans.md) | Alternatives that are multiple words |
| 10 | [Per-Word Clearing](per-word-clearing.md) | Preserve alts when editing text |
| 11 | [Action Words](action-words.md) | Words that trigger external actions |
| 12 | [Auto-Submit](auto-submit.md) | Automatic analysis as you type |
| 13 | [Cursor Export](cursor-export.md) | Export cursor position for external tools |
| 14 | [Status Display](status-display.md) | Show word info in secondary display |
