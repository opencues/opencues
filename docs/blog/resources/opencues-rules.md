# OpenCues Rules

The rules that OpenCues must obey, in order of importance:

1. **Claude Code capable** — must be feasible in Claude Code
2. **Terminal format** — only use formats that are available in Claude's terminal
3. **Unintrusive** — Any additional functionality should not interfere. I can just type as usual.
4. **Only three colours** — to match markdown
5. **Visually apparent** — I shouldn't have to guess or interact to make sense of what I see.
6. **Stateless** — I should not have additional mental burden or keeping it in mind
7. **Cross-platform** — functionality should work on mobile and various keyboards (Mac etc)
8. **No saccades** — I shouldn't have to look away from the prompt line to see options
9. **No jumping** — should not divert attention by frequently changing size, color or reflowing
10. **Visible** — the prompt text currently being actively modified must be visible
11. **Skuemotion** — Pressing an arrow key should make the selection move in that direction
