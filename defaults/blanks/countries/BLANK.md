Implementation: built-in `CountriesBlank` in `@opencues/runtime`
(`packages/opencues-runtime/src/blanks/countries.ts`). One blank, many
facts: the keyword phrase tells the runtime which field to extract. The
data is BUNDLED OFFLINE — `countries-data.ts` (250 countries, generated by
`scripts/gen-countries-data.cjs` from mledoze/countries + samayo/country-json).
No network call, no auth, instant. (It used to fetch restcountries.com, but
that API was fully deprecated June 2026 — bundling makes the blank immune
to that. Re-run the generator to refresh the stable facts.)

Examples:
- `population of France _` → `67.7M`
- `capital of Japan _` → `Tokyo`
- `currency of Brazil _` → `Brazilian real (BRL)`
- `area of Russia _` → `17,098,242 km²`
- `languages of India _` → `Hindi, English`

Multi-word country names + aliases work (`united states`, `south korea`,
`usa`, `uk`) — the bundled table is indexed by common name, cca2/cca3
codes, and altSpellings. ReadOnly: cycling is no-op.
