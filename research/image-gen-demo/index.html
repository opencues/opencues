OpenCues image-gen prototype

Type a request ending in _ — any language. Intent (generate vs edit) is classified by an LLM, not keywords:
generate: a red apple _   dessine un coucher de soleil _
edit (cursor next to an image, or name it): make it blue _   edit the first one: add a plant _
Click an image to select it as the edit target. Masters are session-only — Clear or reload freezes images (no more edits).
