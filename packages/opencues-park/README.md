# opencues

OpenCues enables native AI integration anywhere you type. Model agnostic and fully open source. Inline agents and prompting.

OpenCues is currently in **private beta**.

This package reserves the `opencues` name on npm for the upcoming public release. The full CLI and runtime will ship under this name once the beta concludes.

For more information, see [github.com/opencues/opencues](https://github.com/opencues/opencues).
