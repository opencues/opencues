IMPORTANT - How to identify CONCEPT links:
1. Ask: "If I change word A, must word B logically change too?"
2. Look for CATEGORY PAIRS - a profession needs its workplace, an animal needs its habitat, a tool needs its activity
3. GENERALIZE: If "doctor↔hospital" is a link, then ANY profession↔workplace is a link (mechanic↔garage, plumber↔pipes, etc.)
4. The pattern matters, not the specific words. Learn: profession→workplace, animal→habitat, tool→activity, language→country, etc.

CONCEPT link patterns to recognize:
- Person doing job + place they work = LINK (nurse↔clinic, waiter↔restaurant)
- Animal + where it lives = LINK (lion↔savanna, bat↔cave)
- Tool/software + what it's used for = LINK (Photoshop↔photos, VSCode↔code)
- Activity verb + tool used = LINK (cutting↔saw, typing↔keyboard)

CREATOR↔CREATION pattern (very important - applies to history, science, business, arts):
- If X CREATED/INVENTED/DISCOVERED something → X↔that thing (Edison↔lightbulb, Einstein↔relativity)
- If X WROTE/COMPOSED a work → X↔that work (Shakespeare↔Hamlet, Mozart↔symphonies)
- If X FOUNDED/LEADS/RULES/GOVERNED a place → X↔that place (Napoleon↔France, Caesar↔Rome)
- If X RUNS/MANAGES/LEADS/HEADS/CONTROLS/DIRECTS a company → X↔that company (Tim Cook↔Apple, Satya Nadella↔Microsoft)
- If COMPANY MAKES/BUILDS/PRODUCES product → company↔product (Apple↔iPhone, Tesla↔cars)
- If ARTIST PLAYS/PERFORMS genre → artist↔genre (Beatles↔rock, Picasso↔cubism)

NAMES pattern (always link first name ↔ surname):
- First name and surname of the SAME PERSON must be linked (Elon↔Musk, Steve↔Jobs, Albert↔Einstein)
- If you change the first name, you must change the surname too
- This applies to all people: Elon Musk, Bill Gates, Mark Zuckerberg, Marie Curie, etc.

Do NOT link:
- Random nouns in the same sentence (cat↔mat, pizza↔coffee)
- Subject↔verb unless there's agreement constraint (cat↔sat is NOT a link)
- Words that just happen to be near each other
- Only link words that MUST change together for consistency
